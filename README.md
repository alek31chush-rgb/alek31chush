# Вайбкодинг — подписная страница

Самодостаточная адаптивная страница на HTML, CSS и JavaScript без сборки и внешних зависимостей. Чтобы посмотреть её, откройте `index.html` в браузере.

## Перед публикацией

1. В конце `index.html` задайте `SETTINGS.maxChannelUrl` — полную HTTPS-ссылку приглашения в ваш канал MAX. Пока ссылка не указана, кнопки честно сообщают, что канал ещё не подключён.
2. Настройте в MAX фактическую выдачу подарка после подписки: сообщение или инструкцию о том, как получить семидневный доступ к курсу на Goodly.pro, и инструкцию по созданию канала MAX.
3. Проверьте содержимое курса, сроки и состав бесплатного доступа, а также условия и стоимость платных уроков. Страница описывает пробный доступ, но не проверяет подписку и не выдаёт доступ автоматически.
4. Убедитесь, что формулировки о лицензии, правах перепродажи и выплатах соответствуют актуальным условиям конкретного продукта на Goodly.pro.

Результат продаж не гарантируется. Страница ссылается на канал MAX; проверяйте его содержимое и условия доступа самостоятельно. Сайт не проверяет подписку и не выдаёт доступ к Goodly.pro автоматически.
